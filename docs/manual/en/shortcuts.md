# Keyboard shortcuts

Shortcuts don't apply while you're typing in a text field. **⌘/Ctrl** is ⌘ on a Mac and Ctrl on
Windows and Linux.

## Transport

| Key           | Action                              |
| ------------- | ----------------------------------- |
| Space         | Play / pause (stops a recording)    |
| R             | Record (press again to stop)        |
| Home or Enter | Go to the start                     |
| End           | Go to the end of the last clip      |
| L             | Loop on / off                       |
| C             | Metronome on / off                  |
| T             | Tap tempo (tap along with the beat) |

## Editing

| Key                                 | Action                                                           |
| ----------------------------------- | ---------------------------------------------------------------- |
| ⌘/Ctrl + Z                          | Undo                                                             |
| ⇧ Shift + ⌘/Ctrl + Z, or ⌘/Ctrl + Y | Redo                                                             |
| ⌘/Ctrl + A                          | Select all clips                                                 |
| Escape                              | Clear the selection; cancel a drag                               |
| S                                   | Split the selected clips (or the selected track) at the playhead |
| ⌘/Ctrl + D                          | Duplicate the selected clips                                     |
| Delete or Backspace                 | Delete the selected clips, or the selected track                 |
| N                                   | Snap to grid on / off                                            |
| ⌘/Ctrl while dragging               | Ignore snapping                                                  |
| Alt + drag a clip up or down        | Change the clip's volume                                         |

## View

| Key                                    | Action                |
| -------------------------------------- | --------------------- |
| + / −                                  | Zoom in / out         |
| ⌘/Ctrl + mouse wheel, or pinch         | Zoom                  |
| Shift + mouse wheel, or swipe sideways | Scroll the timeline   |
| X                                      | Show / hide the mixer |

## Tune editor

These work while the mouse pointer is over the editor.

| Key                  | Action                                       |
| -------------------- | -------------------------------------------- |
| ↑ / ↓                | Move the selected notes a semitone up / down |
| Shift + ↑ / ↓        | Move them an octave                          |
| ⌘/Ctrl + A           | Select all notes                             |
| Escape               | Clear the selection                          |
| Alt while dragging   | Free pitch (no semitone snapping)            |
| Mouse wheel          | Scroll                                       |
| ⌘/Ctrl + mouse wheel | Zoom in time                                 |
| Alt + mouse wheel    | Zoom in pitch                                |
